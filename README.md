# Wodmart React Project

Furniture eCommerce HTML template converted to React.

## Setup Instructions

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Copy Assets from original zip
Extract the original `wodmart_vercel_app.zip` and copy the `assets` folder into `public/`:
```
wodmart-react/
  public/
    assets/
      css/
      js/
      images/
      fonts/
```

### Step 3: Run Development Server
```bash
npm run dev
```
Open: http://localhost:5173

### Step 4: Build for Production
```bash
npm run build
```
